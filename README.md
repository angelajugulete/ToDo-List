# Weekly ToDo List in Python

Acesta este un planner saptamanal simplu, cu interfata grafica, scris in Python folosind tkinter. Aplicatia permite adaugarea, editarea si salvarea automata a task-urilor pentru fiecare zi a saptamanii, precum si adaugarea de notite generale.

## Functionalitati

- Planner pentru 7 zile (luni - duminica)
- Adaugare si stergere task-uri
- Marcarea task-urilor ca fiind completate
- Alegerea culorii task-urilor (important, mediu, redus)
- Salvare automata a datelor in fisier JSON (`weekly_planner.json`)
- Sectiune separata pentru notite
